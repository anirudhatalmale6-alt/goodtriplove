# Workflow DSA / Content Notice

À adapter après qualification juridique de GoodTripLove.

## Signalement
Formulaire:
- URL / identifiant du contenu
- motif
- explication
- coordonnées du déclarant lorsque requises
- déclaration de bonne foi
- pièces justificatives facultatives

## Cycle
received -> triage -> under_review -> action/no_action -> notification -> appeal/closed

## Actions
- aucune action
- masquer
- désindexer
- retirer
- limiter la visibilité
- suspendre le compte
- restaurer

## Journal
Conserver:
- date
- contenu concerné
- motif
- éléments examinés
- décision
- base de la décision
- modérateur
- date de notification
- recours éventuel

Ne pas supposer que toutes les obligations DSA s'appliquent de façon identique:
elles dépendent de la qualification et de la taille du service.
