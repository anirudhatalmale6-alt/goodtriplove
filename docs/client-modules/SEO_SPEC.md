# GoodTripLove SEO Specification

## URL structure

Examples:
- /fr/portugal
- /fr/portugal/porto
- /fr/portugal/porto/restaurants
- /fr/portugal/porto/local-food
- /fr/portugal/porto/hotels
- /fr/portugal/porto/guest-houses
- /fr/portugal/porto/places-to-visit
- /fr/portugal/porto/activities
- /fr/portugal/porto/restaurants/place-slug

## Required tags
- title
- meta description
- canonical
- hreflang
- Open Graph
- robots index/noindex
- breadcrumbs
- structured data where appropriate

## Sitemaps
Generate separate chunks for:
- countries
- cities
- categories
- places
- videos if indexable
- localized URLs

## Important
Avoid creating millions of thin pages with no useful content.
Pages should only be indexable when they contain meaningful unique content.
